01

研究边界与设备分类

封装设备不能按“一道工序 = 一台机器”简单枚举：一项固晶工序可能需要点胶、拾取、对准、压合、固化；同一等离子处理设备又可服务多个环节。传统引线键合、倒装芯片、Fan-Out 与 2.5D / 3D 也不是同一条生产线。

01◆

准备与芯片贴装

清洗、拾取、点胶、固晶与固化

02⌁

电气互连

焊线、倒装、热压与混合键合

03⬡

密封与保护

底填、模塑、盖板与散热

04▦

外部端子成型

电镀、植球、回流与引脚形成

05✧

后处理

去溢胶、打标、分离与装盘

06⊙

过程检测

AOI、X-ray、SAM、拉剪力与翘曲检测

i

与原报告其他章节的边界

晶圆减薄和初次切割主要对应第七节；封装后成品电测及可靠性验证主要对应第九节。本页重点关注封装组装设备，以及先进封装特有的晶圆级微加工设备。上述六类是功能分组，并非固定线序。

!

关键技术不可混为一谈

焊料回流依赖焊料熔融；TCB 使用受控温度与压力形成互连；铜-介质 Hybrid Bonding 还要求极高的表面清洁度、平坦度和精密对准。它们不应使用同一组核心性能指标直接排名。

05

关键性能指标框架

设备名称并不构成技术评估。应在相同产品规格、材料、节拍和产能条件下比较性能，避免直接使用厂商宣传的单一最高值。

固晶机
贴装精度（μm）、UPH、最小 Die 尺寸、翘曲适应能力、胶层厚度控制
焊线机
Wires/s、焊盘间距、线材兼容性、线弧控制、在线焊点监测
TCB 键合机
对准精度、温度均匀性、压力控制、键合周期、薄芯片处理能力
Hybrid Bonder
Overlay 精度、颗粒污染控制、界面空洞、表面平坦度、产能
点胶 / 底填设备
点胶重复精度、流量、轨迹、黏度适用范围、空洞率
模塑设备
模塑面积、厚度一致性、翘曲、空洞、冲线风险、UPH
晶圆电镀设备
镀层均匀性、填孔能力、缺陷率、膜厚、沉积速率
回流焊炉
温度曲线及均匀性、氧含量、真空度、焊点空洞率
AOI / X-ray / SAM
缺陷检出能力、误报率、分辨率、检测速度、缺陷类型覆盖
Trim & Form
SPM、引脚共面性、毛刺、成型精度、模具寿命

指标为后续调研问题清单，不代表任何具体设备的承诺规格。

06

研究路线与下一步

按封装产品定义设备优先级，避免将完全不同的设备赛道混为一个“封装设备市场”。

TRACK 01 / 基础主线

QFN / SOP / QFP

固晶机、焊线机、转移模塑机、切筋成型机

重点：传统封装的产能、良率与自动化效率。

TRACK 02 / 重点方向

FCBGA / 高性能处理器

RDL、凸块电镀、倒装键合、TCB、Underfill、植球

重点：高 I/O 密度、互连可靠性及散热。

TRACK 03 / 重点方向

Fan-Out / WLP

重构贴装、压缩模塑、临时键合 / 解键合、RDL

重点：大面积加工、翘曲与细线宽控制。

TRACK 04 / 深入方向

2.5D / 3D / HBM 相关

TSV、CMP、Hybrid Bonding、精密堆叠及界面检测

重点：高密度堆叠、细间距互连与整体良率。

TRACK 05 / 专门分支

SiC / IGBT 功率封装

银烧结、真空回流、粗线楔焊、散热组件装配

重点：高温、大电流及热机械可靠性。

建议的研究优先级

PRIORITY 01

建立通用后道设备的原理基础

固晶机、焊线机、模塑机、倒装键合机。重点确认运动系统、精度、产能、材料适配及在线检测。

PRIORITY 02

研究先进封装设备链

RDL 曝光 / 电镀、TCB、Underfill、临时键合 / 解键合。建立不同工艺之间的依赖关系。

PRIORITY 03

深入高密度堆叠与良率控制

混合键合、TSV、CMP、晶圆级精密检测。结合材料表面、工艺窗口与失效模式分析。

尚待补充的证据

公开实机视频相对不足的设备包括：去溢胶、端子电镀、量产级 BGA 植球、散热盖板贴装、部分固化炉、Fan-Out 重构线、临时解键合、TSV 深硅刻蚀及 CMP。

建议将后续研究的基本记录格式统一为：设备编号 → 原理 → 关键部件 → 适用封装 → 技术指标 → 代表机型 → 视频证据 → 资料来源 → 验证状态。
