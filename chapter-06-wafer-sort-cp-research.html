01 / Research Scope

研究范围与关键判断

晶圆测试（Wafer Sort / CP）在晶圆尚未切割、封装之前，以探针接触方式对裸片（Die）开展电性和功能测试，形成 Pass/Fail、性能 Bin、失效分布和 Wafer Map 等结果，并将数据交付后续工序。

核心判断

量产 CP 不是一串各自独立运行的机器，而是 Prober + ATE + Probe Card + Interface 共同组成的测试单元。温控、搬运、清洁、数据采集和专用仪表围绕它提供能力；其中若干功能可被集成到主机台内。

报告中的典型八步流程

STEP 01晶圆上机Loading / ID / 定位
STEP 02探针卡对准Alignment / Touchdown
STEP 03参数测试DC / Leakage / IV
STEP 04功能测试Pattern / Scan / Memory
STEP 05性能分档Speed / Power / Bin
STEP 06失效分类Fail Code / Diagnostics
STEP 07晶圆图生成Wafer Map / Yield
STEP 08数据传递MES / Downstream
02 / Test Cell

CP 测试单元的设备连接关系

Prober 负责精密机械动作与探针接触，ATE 负责电信号生成及测量，Probe Card 和 Docking Interface 构成电气/机械桥梁。控制软件协调测试脚本、设备状态和数据记录。

04 / Core Equipment

四大核心设备：功能、参数与代表厂商

XY↕

A1 · 全自动晶圆探针台

Automatic Wafer Prober

执行 Wafer Loading、Optical Alignment、Die Stepping、Touchdown、Overdrive 与自动下片，是晶圆和探针卡之间精密接触的核心平台。

重点评价指标
  • 200/300 mm 晶圆支持、XY/Z 精度、接触力与重复定位
  • 温度范围、并测规划、换片及清针时间、UPH
代表厂商 / 机型

TEL：Precio XL / octo；ACCRETECH：AP3000/AP3000e、UF2000；SEMICS：OPUS；FormFactor：CM300xi、SUMMIT200（偏工程研究）。

定位：精密运动 / 自动化 / 热管理
ATE

A2 · 自动测试设备

Automated Test Equipment

利用数字通道、PMU、模拟仪表、电源与射频模块输出测试激励、采集响应，执行功能、电性、时序、功耗测试与分档。

重点评价指标
  • 通道数、最高矢量速率、电源能力、测量精度
  • 多站点效率、测试软件、仪表扩展、CoT
代表厂商 / 机型

Advantest：V93000 EXA Scale、T5835；Teradyne：UltraFLEXplus、Magnum 7H；Cohu：Diamondx；Chroma：3650-S2 / 3680。

定位：信号激励 / 高精度测量 / 并行化
MEMS

A3 · 探针卡

Probe Card

在测试系统与晶圆 Pad / Bump 之间建立可重复的微尺度电气接触。典型技术有 Cantilever、Vertical、MEMS，以及高频、高功率特殊探针。

重点评价指标
  • 针数、Pitch、共面性、接触电阻与清洁周期
  • Scrub Mark、寿命、信号完整性与热形变
代表厂商

FormFactor、Micronics Japan（MJC）、Technoprobe、Nidec SV Probe；国内可关注强一半导体。

定位：高定制化治具 / 接触可靠性
I/O

A4 · 测试接口与对接系统

Test Interface / Docking

由测试头、Pogo Tower、Probe Interface Board、Docking Mechanism 及支撑/操纵系统组成，确保机械定位、供电和高速信号路径稳定。

重点评价指标
  • Signal / Power Integrity、接触一致性、散热与机械形变
  • 维护便利度、对接重复性、平台兼容
适配关系

通常与 ATE 架构、探针卡类型以及 Prober 机械规格共同定制，不能简单按通用线缆选型。

定位：机械与电气连接 / SI & PI
05 / Supporting & Specialty

量产配套系统与专用测试设备

温控 / 装载 / 清洁

自动测试的真实吞吐量不仅由电性测试时间决定，还受换片、对准、温度稳定和针卡维护制约。

  • Thermal Chuck / Chiller：温度均匀性、稳定速度、带载能力；关注 ERS 等厂商。
  • Wafer Handling：FOUP/Cassette、ID、薄片/翘曲晶圆兼容。
  • Probe Card Analyzer：针尖三维位置、共面性、电气连通和漏电；关注 Technoprobe Athena。
  • Cleaning / PMI：在线针尖清洁、针痕视觉检测及维护策略。

射频 / 光电 / 功率测试

特种芯片的测试边界由 DUT 的物理特性决定，无法直接套用通用 SoC 测试平台。

  • RF / mmWave：VNA、校准基片、探针及线缆去嵌入。
  • Silicon Photonics：激光源、光纤阵列、光功率计与自动光耦合。
  • SiC / GaN：高压防护、大电流、Kelvin 接触及安全联锁。
  • WLBI：特定产品的整片/多片晶圆长期电热应力筛选；可研究 Aehr FOX-XP 与 WaferPak。

数据与工厂自动化

Wafer Map、Bin Map、STDF 数据与 MES 串联测试单元和后续切割、封装流程。

  • Die 坐标、软硬 Bin、Re-test / Inkless Map 管理
  • 工单、批次、追溯及良率分析
  • SECS/GEM、设备日志及故障诊断
  • 良品数据接口与下游交付一致性

存储器修复与先进封装

HBM、KGD 和 Chiplet 对高覆盖率晶圆级筛选提出更高要求，同时会改变并测/温控/数据策略。

  • Memory Repair：冗余分析、Laser Fuse 或 eFuse；不是所有产品都使用激光。
  • HBM：高密度连接与大规模并行化，需明确测试阶段。
  • KGD：尽量在封装前识别不良 Die，提升后续集成收益。
  • WLBI：非所有逻辑、存储器和功率芯片都必经的通用 CP 工序。

08 / Performance Economics

评价设备不能只看名义测试速度

投资、采购与技术评估需要关注实际吞吐量、良率影响、维护损失和生命周期成本，而不只是宣传资料中的 Peak Throughput。

测试能力

精度、覆盖率、通道数、模式速率、测试供电和温度能力。

并行效率

Site Count、真实并测收益、资源冲突和测试程序优化。

接触质量

Contact Resistance、共面性、重测率、针痕与针尖寿命。

有效稼动

UPH、MTBF、换片/温稳/清洁/换卡及停机时间。

品质风险

False Reject、潜在漏检、重测策略、温漂和测试相关性。

综合成本

CAPEX、厂务、维保、人力、探针卡和测试治具摊销。

Cost per Tested Die =单位时间测试单元综合成本单位时间实际完成测试的 Die 数量分母应考虑重测、换片、清针、温度稳定与停机；不是标称理论峰值。
09 / Technical Boundaries

四个不能混淆的工艺边界

01
WAT / PCM ≠ CP

WAT / PCM 更多面向器件参数与晶圆制造过程控制，CP 面向 Die 功能和电性筛选。它们可能共用仪表方法，但测试目标、程序和设备配置并不相同。

02
CP ≠ 封装后 Final Test（FT）

FT 常见的封装器件 Handler、Socket、Load Board 并非 CP 核心设备。部分 ATE 可跨工序使用，但对接、治具和测试环境不同。

03
Memory Repair ≠ 必须使用激光

Laser Fuse 和 eFuse 是不同实现方式，具体工艺取决于芯片设计与制造平台；激光修复设备不是通用 CP 的必需站点。

04
先进封装改变测试策略，但不存在一套通用配方

HBM / KGD / Chiplet / WLBI 增加测试复杂性；不同芯片的最佳并测数、温度条件、接触技术及测试覆盖率必须单独建模。

10 / Research Roadmap

后续建议的研究路线

P0 · 优先

打通完整 CP 单元

建立 Prober、ATE、Probe Card、Docking 的信号链、机械链、时序和控制链，解释完整测试循环。

P1 · 扩展

按产品做设备矩阵

分别研究 SoC、DRAM / NAND / HBM、模拟、功率、RF 和硅光的配置差异。

P2 · 深化

验证厂商技术壁垒

关注实测参数、客户认证、测试软件生态、服务、耗材寿命与生命周期成本。
